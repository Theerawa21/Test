# TCAS Portfolio Entry – Saint Theresa School

เว็บ GitHub Pages สำหรับให้นักเรียนกรอกรหัสประจำตัวนักเรียน ตรวจสอบชื่อ–นามสกุล/เลขประชาชน และบันทึกข้อมูล 4 ประเภทลง Google Sheets:

- `activities`
- `prizes`
- `projects`
- `certs-courses`

## การทำงานของนักเรียน
1. นักเรียนกรอกรหัสประจำตัวนักเรียน
2. Backend Apps Script อ่านรายชื่อจากฐานนักเรียนและคืนข้อมูลเฉพาะนักเรียนคนนั้น
3. นักเรียนยืนยันชื่อ–นามสกุล ชั้น/ห้อง และเลขประชาชน
4. เลือกกรอกกิจกรรม รางวัล โครงงาน หรือหลักสูตร/Certificate
5. Backend เป็นผู้เติม `citizen_id`, `title`, `first_name`, `last_name` จากฐานนักเรียนก่อนเขียนลงชีต นักเรียนไม่สามารถแก้ข้อมูลระบุตัวตนเองได้

## ระบบสำหรับครู
หน้าเว็บมีปุ่ม `👩‍🏫 สำหรับครู` ที่มุมขวาบน ครูสามารถ:

- ดูสรุปนักเรียนทั้งหมด
- เลือกดูเป็นรายห้อง
- เห็นจำนวน `ส่งแล้ว` / `ยังไม่ส่ง`
- เห็นจำนวนรายการผลงานทั้งหมดของแต่ละห้อง
- ดูจำนวนแยกเป็น กิจกรรม / รางวัล / โครงงาน / หลักสูตร
- ค้นหาด้วยรหัสนักเรียน ชื่อ หรือนามสกุล
- กรองเฉพาะนักเรียนที่ส่งแล้วหรือยังไม่ส่ง
- กดดูรายละเอียดข้อมูลทั้ง 4 ประเภทของนักเรียนรายบุคคล

ระบบครูใช้ session ฝั่ง Apps Script และจะไม่ส่งเลขประจำตัวประชาชนมาแสดงใน Dashboard ครู

## ตั้งรหัสสำหรับครู
เพื่อไม่ให้รหัสครูอยู่ใน GitHub ให้ตั้งรหัสไว้ใน Apps Script Script Properties

1. เปิด Apps Script project
2. ไปที่ **Project Settings**
3. เลื่อนลงไปที่ **Script Properties**
4. เพิ่ม Property:
   - Property: `TEACHER_CODE`
   - Value: รหัสที่ต้องการใช้สำหรับครู
5. บันทึก

## ติดตั้ง / อัปเดต Backend Google Apps Script
1. เปิด Apps Script project ที่ใช้เป็น API
2. นำโค้ดจาก `apps-script/Code.gs` ไปแทน `Code.gs` เดิมทั้งหมด
3. Run `setupSheets()` 1 ครั้งถ้ายังไม่เคยตั้งค่าชีต
4. ตั้ง `TEACHER_CODE` ใน Script Properties
5. ไปที่ **Deploy > Manage deployments**
6. กดแก้ไข Deployment เดิม
7. เลือก **New version** แล้วกด Deploy
8. ใช้ Web App URL `/exec` เดิมได้ ไม่ต้องเปลี่ยน URL ใน GitHub
